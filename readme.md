# 小说设定管理器

这是一个使用 FastAPI 和纯 Python 技术栈构建的 Web 应用，旨在为小说作者、编剧和世界观构建者提供一个高度灵活、结构化的设定管理工具。

与传统的笔记应用不同，本工具允许你自定义设定的**类型**和**字段**，并通过内部链接构建一个可交互的知识网络，完美适配任何复杂或独特的世界观。

## ✨ 主要功能

* **多小说管理**: 创建和管理多部小说的设定集。
* **动态设定类型**: 自由创建任何需要的设定分类，如“角色”、“武器”、“功法”、“地点”、“势力”等。
* **动态字段系统**: 在每个设定条目（如一个具体的角色）下，可以自由添加、编辑和删除任意数量的自定义字段（如：年龄、门派、称号）。
* **无刷新内联编辑**: 在设定详情页直接编辑条目内容，无需跳转，提供流畅的“所见即所得”编辑体验。
* **手动排序**: 通过简单的拖拽或点击按钮，可以手动调整设定类型、设定条目以及条目内字段的显示顺序。
* **内部链接系统**: 使用 `[[条目名称]]` 语法，可以在设定的描述文本中轻松创建指向其他设定条目的内部链接，方便快速跳转和查阅。
* **Markdown 支持**: 所有文本字段均支持 Markdown 语法，可以轻松编写格式丰富的长文本描述。
* **现代化交互界面**:
    * 详情页拥有可随内容滚动的悬浮目录，方便快速定位。
    * 设定条目可自由展开和收起，保持页面整洁。
    * 所有删除操作均有二次确认弹窗，防止误删。

## 🛠️ 技术栈

* **后端**: Python 3, FastAPI
* **数据库**: SQLite (通过 SQLAlchemy ORM 进行操作)
* **前端**: HTML5, CSS3, Vanilla JavaScript (无前端框架)
* **模板引擎**: Jinja2
* **Markdown解析**: markdown2

## 🚀 快速开始

请按照以下步骤在你的本地计算机上运行此项目。

**1. 环境准备**

* 确保你已经安装了 Python 3.7 或更高版本。

**2. 创建并激活虚拟环境**

```

# 在项目根目录创建一个名为 venv 的虚拟环境

python -m venv venv

# 激活虚拟环境

# Windows:

venv\\Scripts\\activate

# macOS / Linux:

source venv/bin/activate

```

**3. 安装依赖**

```

pip install fastapi "uvicorn[standard]" sqlalchemy jinja2 markdown2

```

**4. 运行应用**

```

# 在项目根目录运行此命令

uvicorn app.main:app --reload

```

服务启动后，你就可以在浏览器中访问 `http://127.0.0.1:8000` 来查看和使用应用了。

**⚠️ 重要提示：数据库初始化**

* 应用首次启动时，会自动在项目根目录创建一个名为 `novel_settings.db` 的数据库文件。
* 如果你你在开发过程中修改了 `app/models.py` 中的数据库模型，你需要**手动删除** `novel_settings.db` 文件，然后重启应用，以便程序能根据新的模型创建正确的数据库表。

## 📖 使用指南

1.  **创建小说**: 进入首页，点击“创建新小说”按钮，填写信息即可创建一部小说。
2.  **创建设定类型**:
    * 点击进入任意一部小说的详情页。
    * 点击右上角的“添加新设定”下拉菜单，选择“新建设定类型...”。
    * 输入类型名称（例如：“角色”、“功法”），保存。
3.  **创建设定条目**:
    * 在小说详情页，再次点击“添加新设定”，此时下拉菜单中会出现你刚刚创建的类型（如“添加 角色”）。
    * 点击后，填写该条目的名称（例如：“李青云”），保存。
4.  **内联编辑与添加字段**:
    * 保存条目后，页面会自动刷新。找到你刚刚创建的条目“李青云”。
    * 点击其右侧的“编辑”按钮，进入内联编辑模式。
    * 在此模式下，你可以修改名称，并通过“添加新字段”按钮自由地为“李青云”添加任意字段，如“年龄”、“修为”、“持有武器”等。
    * 字段值支持 Markdown 语法。
5.  **使用内部链接**:
    * 假设你已经创建了名为“冰魄寒光剑”的武器条目。
    * 在编辑“李青云”的“持有武器”字段时，你可以这样写：`他的佩剑是[[冰魄寒光剑]]`。
    * 保存后，在查看模式下，“\[\[冰魄寒光剑\]\]”会自动变成一个可以点击的蓝色链接，直接定位到武器的设定卡片。
